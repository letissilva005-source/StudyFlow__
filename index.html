StudyFlow

Organizador de Rotina Universitária

Sobre o Projeto

O StudyFlow é um sistema desenvolvido para ajudar estudantes universitários a organizar disciplinas, tarefas, provas e horários de estudo.

Funcionalidades Futuras

  • Cadastro de disciplinas
  • Lista de tarefas
  • Calendário de provas
  • Planejamento de estudos
